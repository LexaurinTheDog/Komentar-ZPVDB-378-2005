# Komentář k zákonu č. 378/2005 Sb., o podpoře výstavby družstevních bytů ze Státního fondu podpory investic, a o změně zákona č. 190/2004 Sb., o dluhopisech, (zákon o podpoře výstavby družstevních bytů)

Otevřený komentář k zákonu o podpoře výstavby družstevních bytů — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; podmínky a výše podpory ze Státního fondu podpory investic, žádost a smlouva, čerpání a zúčtování, stanovy, členství a majetek bytového družstva, které je příjemcem podpory, ukončení závazků a kontrola.

Konsolidované znění: dokument e-Sbírky `SB-2005-00378_2020-06-01`.
